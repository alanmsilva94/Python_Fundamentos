# Repositório de Exercícios de Fundamentos do Python

Bem-vindo ao meu repositório de exercícios de fundamentos do Python! Aqui você encontrará diversos exercícios básicos que abrangem os conceitos essenciais da linguagem.

## Sobre
Este repositório foi criado com o objetivo de armazenar e compartilhar exercícios que auxiliam no aprendizado dos fundamentos do Python.

## Tópicos abordados
- Sintaxe básica
- Variáveis e tipos de dados
- Estruturas condicionais
- Laços de repetição
- Funções
- Listas, tuplas e dicionários
- Manipulação de strings
- Entrada e saída de dados
- Tratamento de erros e exceções

## Contribuição
Se você quiser contribuir com novos exercícios ou melhorias, fique à vontade para abrir um Pull Request!
